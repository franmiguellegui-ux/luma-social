# Luma Social

Sitio web para una marca ficticia de Community Management, creado como proyecto final del curso de Desarrollo Web de CoderHouse.

## Descripción del proyecto

Luma Social es una propuesta de sitio web pensada para ayudar a emprendedores nuevos a mejorar su presencia en redes sociales.

El sitio presenta diferentes servicios relacionados con la comunicación digital:

- Gestión de redes sociales.
- Publicidad en redes sociales.
- Creación de contenido.

También incluye una sección de portfolio con proyectos ficticios, información sobre la marca y un formulario de contacto.

## Objetivo

El objetivo principal del proyecto es crear un sitio web claro, atractivo y adaptable a distintos dispositivos, que permita presentar los servicios de una Community Manager y atraer posibles clientes.

## Público objetivo

El sitio está dirigido principalmente a:

- Emprendedores nuevos.
- Pequeños negocios.
- Marcas que necesitan mejorar su presencia digital.
- Personas que quieren comenzar a trabajar con redes sociales.

## Páginas del sitio

El proyecto está compuesto por cinco páginas:

- `index.html`: página principal o inicio.
- `pages/servicios.html`: información sobre los servicios ofrecidos.
- `pages/portfolio.html`: muestra de proyectos ficticios.
- `pages/sobre-nosotros.html`: presentación de la marca, misión, visión y valores.
- `pages/contacto.html`: formulario y medios de contacto.

## Tecnologías utilizadas

- HTML5.
- CSS3.
- Sass/SCSS.
- Bootstrap.
- AOS para animaciones.
- Git y GitHub.
